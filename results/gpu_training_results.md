## 1. 회복 챗봇 SFT (54번, A5000 × 8)

선생 Qwen3-30B 가 대응 지침을 보고 만든 답을 체크리스트로 거른 데이터. 위험 모드 턴은 3배 반복.
설정: LoRA r 16, lr 1e-4 cosine, 2 epoch, max_len 4096, GPU당 배치 1 × grad_accum 4 (유효 배치 32), bf16.

| 버전 | 학습 샘플 | 스텝 | 학습 시간 | train loss (처음 → 끝) | eval loss (100 → 끝) |
|---|---|---|---|---|---|
| SFT v1 | 4,236 | 338 | 33분 | 1.364 → 0.509 | 0.658 → 0.568 |
| SFT v2 | 4,157 | 330 | 33분 | 1.372 → 0.501 | 0.702 → 0.612 |

v2 는 같은 안전 문장을 반복하는 답(단어 유사도 0.8 이상)을 데이터에서 뺀 버전.

## 2. 회복 챗봇 GRPO (롤아웃 84번, 학습 54번)

한 반복 = 인물 32~64명 × 4표본 대화 롤아웃 → 같은 인물 4개끼리 이점 계산 → 턴 단위 GRPO 1스텝 → 어댑터를 정책 서버에 교체.
보상 R = 0.4·끝 감정/100 + 0.6·위험 감소 − 지침 위반 페널티 (T1 위반 시 −1 바닥).

## 4. 판정기 Kev LoRA 학습 (54번, A5000 1장씩)

공개 Kev(Qwen3.5 기반 + pointer head)에 개발용 데이터의 Jev 답(질문 17개 확률)을 soft target 으로 학습. lr 5e-5, 1 epoch, max_state 4096, gradient checkpointing, bf16.

| 어댑터 | 시작 모델 | 학습 발화 | 발화당 시간 | 학습 시간 |
|---|---|---|---|---|
| kev4b_ft1 | Kev-4B | 3,014 | 6.8초 | 약 6시간 |
| kev9b_ft1 | Kev-9B | 3,014 | 9.3초 | 약 8시간 |
| **kev4b_ft2 (채택)** | Kev-4B | 4,928 | 6.8초 | 약 9시간 |
| kev4b_ft2lr | Kev-4B | 4,928 (lr 1e-4) | 6.8초 | 약 9시간 |

결과 (정밀도 / 감지율 / 특이도, unsafe 만 양성; 괄호는 Jev 와 κ)

| 데이터 | Jev | 공개 Kev-9B (학습 전) | kev4b_ft1 | kev9b_ft1 | **kev4b_ft2** |
|---|---|---|---|---|---|
| CRADLE validation (ID 보류) | 57 / 99 / 91 | 31 / 94 / 74 (0.67) | 62 / 98 / 92 (0.89) | 58 / 99 / 91 (0.88) | **66 / 98 / 94 (0.87)** |
| Reddit C-SSRS (OOD) | 77 / 63 / 95 | 45 / 74 / 76 (0.42) | 59 / 66 / 88 (0.72) | 59 / 67 / 88 (0.73) | **64 / 63 / 91 (0.77)** |
| SIM-VAIL 일상 대화 (unsafe 비율) | 12.3% | 21.3% | 11.0% | 12.3% | 9.3% |

- 학습 전 공개 Kev 는 오탐이 많았다(시점 질문 일치 19~47%) → 학습 후 학습에 안 쓴 데이터에서도 Jev 수준.
- 4B ≈ 9B 라 더 빠른 4B 채택. lr 1e-4 는 5e-5 와 같은 결과.

## 5. 학습 없이 GPU 추론으로 돌린 실험 — 프롬프트 뱅크 최적화

베이스 LLM 고정, 상태별 시스템 프롬프트 조각만 고침 (반성 LLM Qwen3-30B, 챗봇 Qwen3-8B, 84번 30B 3대 + 54번 2대).
20반복, 반복당 약 20~55분.

| 반복 | 고친 조각 | 검증 R (56 대화) | T1 | 채택 |
|---|---|---|---|---|
| 0 (seed) | – | 0.161 | 8.9% | – |
| 9 | assess | 0.208 | 7.1% | ✓ |
| 10 | assess | **0.233** | **3.6%** | ✓ |
| 17·19·20 | 조각 3개 병렬 | 0.23 안팎 | – | 최고 갱신 |

test 150명: R 지금 방식 0.082 → 최적 뱅크 **0.145** (+0.064, 한쪽 p 0.035), T1 13.3% → 8.0%.
같은 뱅크를 재학습 없이 Gemma-3-12B 에 적용 (가드레일 oracle): R +0.154 [+0.065, +0.244], T1 26.0% → 13.3%.
