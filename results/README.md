## 6. 단계 판정: 점수 vs 누적 확률 (2026-10-06)

점수 질문의 단계를 '누적 확률 P(≥k) ≥ 0.5' 대신 'Jev 점수 ≥ k - 0.5' 로 정한다 (사용자 결정). 같은 Jev 답에 두 방식을 적용한 CRADLE test 비교:

| | base | base-eval | expert11 |
|---|---|---|---|
| 대응 수준 일치 | 98.4% | 96.7% | 96.8% |
| 지금 자살·자해 211개 중 놓침 (누적 확률 → 점수) | 4 → 1 | 1 → 0 | 2 → 0 |
| 위기 이전 1814개 중 대응 붙음 | 26 → 31 | 111 → 144 | 264 → 279 |

점수는 확률의 평균이라 높은 단계에 걸친 확률이 절반이 안 돼도 반영되어, 애매한 발화를 조금 더 높게 본다.
시점 점수는 0(해당 없음) 확률을 뺀 평균을 쓰고, 시점 질문이 '해당 없음' 쪽(나머지 < 0.5)이면 시점 불명으로 본다
(그러지 않으면 "Have a good night" 같은 발화가 남은 2% 확률로 '지금' 시점이 되어 즉시 대응이 됐다).
누적 확률 방식은 `common/rules.py` 의 `THRESHOLD_MODE = "cumprob"` 로 되돌릴 수 있다.
