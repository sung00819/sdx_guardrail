# base-eval

base(v4i) 질문 13개 + 전문가 추가 제언 신호 + 자살 행동·자해의 경험과 시점. 질문 27개를 한 번에 묻는다 (`VERSION = el3c`).

| 부분 | 질문 |
|---|---|
| v4i + 추가 신호 | v4i 13개 + C-SSRS 자살 사고 ①~⑤ 점수(최근 1개월), 수단 접근, 급성 위험 맥락, 정신과 병력(입원·장기 정신질환·물질사용장애로 좁힘), 간접 경고신호, 안전 유지 불가, 부인 진술, 만성적 자살 사고, 보호요인 |
| 자살 행동 | 정도 0~4 (없음 / 준비 / 스스로 멈춤 / 저지됨 / 실제 시도) + 가장 최근 행동 시점 0~4 |
| 자해 | 정도 0~3 (없음 / 충동 / 행동 / 반복·심함) + 가장 최근 자해 시점 0~4 + 자해의 자살 의도 (자살적 / 비자살적 / 불명) |

시점 0~4: 없음 / 12개월보다 전 / 3~12개월 전 또는 시점 불명 / 최근 3개월 / 진행 중·오늘. 시점은 시작이나 기간이 아니라 가장 최근 일.

C-SSRS 자살 사고 단계: ① 죽고 싶은 소망 ② 비특이적 능동적 자살 사고 ③ 실행 의도 없이 방법을 생각 ④ 실행 의도 있음 ⑤ 구체적 계획과 의도.

- 질문: [questions.py](questions.py), 수준 규칙: [levels.py](levels.py)

장단점: 현재 위기와 과거 이야기를 거의 놓치지 않고 오탐도 적다. 세 설계 중 균형이 가장 좋다.
