# base

기존 감지 질문 v4i 13개만 쓰고, '자살·자해 점수 ≥ 1.5 이면 무조건 발동' 대신 그 답으로 위험 단계를 나눈다.

- 질문: [questions.json](questions.json)
  - 자살 점수 0~3 (없음 / 부정적 감정 / 소극적 자살 사고 / 적극적 자살 사고·시도), 자해 점수 0~3 (없음 / 간접 언급 / 충동 / 행동)
  - C-SSRS 예/아니오 5개: 방법, 의도, 계획, 준비, 시도
  - 주체(self / both / other / none), 자살·자해 시점(current / past_only / none), 심한 자해, 도움 요청, 기타 위기
- 수준 규칙: [levels.py](levels.py)
- 기존 발동 규칙: [guard_rule.py](guard_rule.py) `decide_final` (발동 / 과거(병렬 전달) / 제외(타인) / 미발동)

장단점: 일반 대화와 위기 이전 발화에서 가장 조용하다. 3·12개월 같은 시점 질문이 없어 과거 시도·자해를 많이 놓친다.
