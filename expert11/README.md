# expert11

전문가 검수 자료(2026-10-02)의 11개 위험평가 기준 항목을 그대로 질문으로 만든 설계. 질문 30개를 한 번에 묻는다 (`VERSION = t11c`).
항목 질문은 시점과 상관없이 '있었는지·얼마나'만 묻고, 시점은 따로 묻는다. 자살 이야기 감지는 v4i 13개를 그대로 포함한다.

| # | 항목 | 값 |
|---|---|---|
| 1 | 자살 행동 | 0 없음 / 1 시도했지만 멈추거나 저지됨(손상 없음) / 2 실제 시도 |
| 2 | 자살 의도 | 0 드러나지 않음 / 1 약간·양가적 / 2 분명함 ('부인함'은 두지 않음: 챗봇이 판단) |
| 3 | 자살 계획 | 0 없음 / 1 방법만 / 2 시기·장소 일부 구체화 / 3 전부 구체화 |
| 4 | 준비 행동 | 0 없음 / 1 수단 탐색 / 2 수단 마련 / 3 죽음 대비(유서, 물건 나눠 주기) |
| 5 | 자살 사고 | 0 없음 / 1 죽고 싶은 소망 / 2 비특이적 능동적 사고 / 3 방법 생각 (C-SSRS ①~③) |
| 6 | 자해 | 0 없음 / 1 충동 / 2 행동 / 3 반복·심함 + 자살 의도 (자살적 / 비자살적 / 불명) |
| 7~11 | 맥락 (예/아니오) | 치명적 수단 접근 · 급성 위험 맥락(구체적 사건·음주·심한 초조·불면) · 정신과 병력·위험요인(전문가 정의대로 넓게) · 간접 경고신호 · 보호요인 · 안전 유지 불가 |
| 시점 | 가장 최근 자살 행동 / 준비 행동 / 자살 사고 / 자해 | 0 없음 / 1 12개월보다 전 / 2 3~12개월 / 3 1~3개월 / 4 1개월 안 / 5 지금 |

시점 불명: 행동·자해는 2(3~12개월, 전문가 자료 '시점 불명 포함'), 사고는 4(1개월 안, 원칙: 확인되지 않은 정보로 낮추지 않음).

- 질문: [questions.py](questions.py), 수준 규칙: [levels.py](levels.py)

장단점: 위험을 가장 높게 본다 (능동적 자살 사고 대부분 '즉시 대응'). 넓게 잡은 병력과 '간접 경고신호 + 급성 맥락' 상향 때문에
위기 이전 발화·일반 대화도 '지지와 추적' 이상으로 올리는 경우가 셋 중 가장 많다.
